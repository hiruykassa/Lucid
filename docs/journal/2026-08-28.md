## The story

**Situation.** S1 closed Aug 14 with three ADRs accepted, but S2 could not start without
an LLD for the empty query skeleton. The fall schedule also turned out to be roughly half
what the original plan assumed (~20 h/week was never measured), and the week of
Aug 17–23 was a wash from illness.

**Task.** Write LLD-0001 so S2 has a frozen HTTP contract before any SAM work. Separately,
count real calendar blocks and resize scope so the plan is honest before S3 starts.

**Action.** On the query skeleton I learned what cited-answer JSON means in this project:
not just an answer string, but an envelope with `refused`, `answer`, and `citations`
(where each citation carries `paper_id` and `page`). I wrote functional, non-functional,
and explicit non-requirements, then froze `POST /query` over GET because S5 needs a
question in the body and I did not want callers to change HTTP method later. I chose HTTP
200 for refusals (the request succeeded; the corpus just had nothing to cite) and picked
a Python handler that returns the Success fixture as a constant with a 10-second timeout.
I rejected console deploy in favor of SAM through GitHub Actions so the live pipe stays
in git.

I missed the refusal shape on the first draft: Success only, no `refused: true` example.
On review I added it before approval so S5 and the eval harness do not invent the
contract under pressure.

On capacity I counted Google Calendar blocks (method in `PLAN.md` §Capacity), dropped
BIOL 105 from the load, and approved ADR-0004's resize: **25–30 papers** and **~35 eval
questions** (~26 answerable, ~9 unanswerable) instead of ADR-0003's 40–50 / ~50. The
trigger is measured hours short before S3, not a blocked collection run.

**Result.** LLD-0001 is approved. S2 gate is implementation, not more design. Bedrock
invoke is verified (ADR-0002 caveat from Aug 14 is closed; S2 still does not need it).
`PLAN.md` now sizes against **135.5 h** of real build time through Dec 13. ADR-0004 is
approved so S3/S6 targets are consistent with that number.

would have to guess the refusal shape under deadline, and the eval harness cannot measure
refusal until the contract exists. I added `refused: true` with empty `citations` before
approval.

I also treated the original "~20 h/week" plan as real until I counted the calendar. The
first count was 71.5 h for the semester (24% of the assumption) before BIOL 105 was
dropped.
